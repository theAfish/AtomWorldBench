# AtomWorldBench

AtomWorldBench is a benchmark and toolkit for evaluating large language models on 3D crystal-structure manipulation tasks.

Use this site for three things:

- Read the installation and CLI guides.
- Explore the Python API and action definitions.
- Open the interactive results dashboard.
